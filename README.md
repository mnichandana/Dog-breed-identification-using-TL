Dog Breed Identification Using Transfer Learning

This project is a dog breed classification system built using deep learning and transfer learning techniques. A pre-trained VGG19 convolutional neural network is fine-tuned on a dataset of dog breed images to accurately identify dog breeds from input images. The system automates breed recognition, which is otherwise difficult and error-prone when done manually.

The trained model is integrated into a Flask web application that allows users to upload dog images through a simple web interface and receive real-time breed predictions. The application processes the uploaded image, performs preprocessing, and displays the predicted breed label along with the image preview. This project demonstrates the practical use of transfer learning for multi-class image classification and can be applied to pet adoption platforms, veterinary support, and animal welfare applications.
